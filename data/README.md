# Dữ liệu nguồn

`olist-brazilian-ecommerce.zip` là bản tải nguyên gốc của bộ dữ liệu
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) trên Kaggle,
gồm 9 file CSV (khoảng 99 nghìn đơn hàng từ 09/2016 đến 10/2018).

- Nguồn: Olist, phát hành trên Kaggle.
- Giấy phép: CC BY-NC-SA 4.0 (ghi nguồn, không dùng cho mục đích thương mại, chia sẻ lại theo cùng giấy phép).
- Repo này giữ nguyên file gốc, không chỉnh sửa, để mọi người chạy lại được mà không cần tài khoản Kaggle.

Giải nén vào `data/raw/` theo hướng dẫn trong `README.md` ở thư mục gốc.
